ZWISCHEN ERZEUGUNG UND GESTALTUNG

Generative AI integriert sich zunehmend in die meisten Bereiche des Designs. Dennoch bleibt die Frage offen, ob sie tatsächlich alle unsere Bedürfnisse erfüllen kann. Dieses Projekt untersucht die Möglichkeiten des Codings mit p5.js im Vergleich zur generativen AI Midjourney anhand von drei Effekten: ASCII Art, Pixelisation und Randomness.

ASCII ART

Prompt-Beispiel: https://s.mj.run/EiP3R1svmU4 ASCII art style, black and white, high contrast, text-like aesthetic, grid of symbols, minimalist, preserve original composition, literal depiction, no extra elements, no faces, no people, no environment, no nature, no t_]()

Code-Beispiel: let img; let tilesX = 24; let tilesY = 24; let font; let chars = "§!%+(*ß"; function preload() { img = loadImage("sp.jpg"); font = loadFont("IBMPlexMono-Regular.ttf"); } function setup() { createCanvas(500, 500); colorMode(HSB, 100); img.resize(tilesX, tilesY); textFont(font); textAlign(CENTER, CENTER); textSize(56); } function draw() { background("#f1f1f1"); noStroke(); let tileW = width / tilesX; let tileH = height / tilesY; translate(tileW / 2, tileH / 2); for (let x = 0; x < tilesX; x++) { for (let y = 0; y < tilesY; y++) { let c = img.get(x, y); let b = brightness(c); let selector = constrain( int(map(b, 0, 100, chars.length - 1, 0)), 0, chars.length - 1 ); fill(0); push(); translate(x * tileW, y * tileH); text(chars.charAt(selector), 0, 0); pop(); } } } function keyPressed() { saveCanvas('mySketch', 'png'); }

Code-Beispiel: let img; let tilesX = 70; let tilesY = tilesX; function preload() { img = loadImage("art.jpg"); } function setup() { createCanvas(500, 500); img.resize(tilesX, 0); noStroke(); } function draw() { let tileW = width / tilesX; let tileH = height / tilesY; for (let x = 0; x < tilesX; x++) { for (let y = 0; y < tilesY; y++) { let c = img.get(x, y); // інверсія кольору let inv = color( 255 - red(c), 255 - green(c), 255 - blue(c) ); fill(inv); rect(x * tileW, y * tileH, tileW, tileH); } } } function keyPressed() { saveCanvas('mySketch', 'png'); }

RANDOMNESS

Prompt-Beispiel: black background with randomly scattered white dots, varying sizes and opacity, white speckles, minimal composition, no extra elements, abstract, high contrast --v 6.0 --ar 1:1 --no faces, people, characters, environment, scenery, nature, trees, forest, landscape, buildings, objects, animals, furniture --raw -

Code-Beispiel: function setup() { createCanvas(400, 400); noStroke(); background(255); for (let i = 0; i < 20; i++) { let x = random(width); let y = random(height); let w = random(20, 80); let h = random(5, 30); fill(random(255), random(255), random(255), random(150, 255)); rect(x, y, w, h); } } function keyPressed() { saveCanvas('mySketch', 'png'); }

Die Ergebnisse zeigen, dass Coding mit p5js eine präzise und detaillierte Anpassung sowie gezielte Kontrolle bestimmter Effekte ermöglicht, während Midjourney unerwartete Bilder generiert und diese nach eigener Logik interpretiert. Daraus wird deutlich, dass generative AI ein interessantes, jedoch kein allmächtiges Tool ist. Ideale Resultate entstehen nur dann, wenn klar verstanden wird, in welchen Bereichen sie unterstützend wirkt und in welchen sie limitiert oder ungeeignet ist.
